# Interactive Web Calculator

A simple, functional calculator built as part of my academic coursework. This project demonstrates core front-end web development concepts, including HTML forms and JavaScript DOM manipulation.

## Features
* Accepts two numerical inputs from the user.
* Includes buttons for Multiplication and Division.
* Instantly calculates and displays the result on the page without reloading.

## Technologies Used
* **HTML5:** For the user interface and input fields.
* **JavaScript:** For capturing inputs, handling arithmetic logic, and updating the HTML to display the result.

## How to Run
1. Download or clone the repository.
2. Double-click the `index.html` file to open it in any web browser.
